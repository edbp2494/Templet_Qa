REQUISITO
   |
   v
"Validar que Sheets render es consistente entre TEST y PROD"
   |
   v
ANÁLISIS QA
   |
   ├─ Tipo de prueba: MAQUETACIÓN
   ├─ Plataforma: WEB
   ├─ Prioridad: ALTA
   └─ Umbral: 3%
   |
   v
DISEÑO TEST CASE
   |
   ├─ TC-SHEETS-LAYOUT-001
   ├─ Pasos: Login → Captura TEST → Login PROD → Captura PROD → Comparar
   ├─ Datos: Credenciales de Profile
   └─ Validación: Diff visual ≤ 3%
   |
   v
IMPLEMENTAR
   |
   ├─ Object Repository XML (elementos)
   ├─ Keywords Groovy (funciones)
   ├─ Test Case XML (orquestación)
   └─ Agregar a Suite
   |
   v
EJECUTAR
   |
   ├─ $ katalon --run --suite Suite-Sheets-Phase1-MVP --profile ENV_TEST
   ├─ Katalon inicia navegador
   ├─ Ejecuta pasos en secuencia
   ├─ Captura logs
   └─ Genera reportes
   |
   v
RESULTADOS
   |
   ├─ HTML Report: Reports/execution_report.html
   ├─ Screenshots: Resources/Screenshots/*.png
   └─ Status: ✅ PASS / ❌ FAIL
