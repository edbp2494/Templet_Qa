🔧 AJUSTES IMPORTANTES ANTES DE EJECUTAR
===============================================================================

1. XPATHS DE ELEMENTOS
   Los XPath en Object Repository están basados en estructura HTML típica.
   Si tu aplicación tiene estructura diferente:
   
   a) Abre la página en navegador (F12 - DevTools)
   b) Inspecciona el elemento (Click derecho > Inspect)
   c) Copia el XPath correcto
   d) Actualiza Object Repository XML correspondiente
   
   Ejemplo:
   Antes:  //table[@id='main-table']
   Después: //div[@class='data-container']//table
   
2. SELECTORES DE LOGIN
   Actualizar si los campos de login usan atributos diferentes:
   
   - username field: name, id, placeholder
   - password field: name, id, type
   - login button: text, id, class
   
3. URLs CORRECTAS
   Verificar que URLs en Profiles coincidan:
   - ENV_TEST: https://sheets-test.templet.io/admin/manager.php
   - ENV_PROD: https://sheets.templet.io/admin/manager.php

❌ TROUBLESHOOTING COMÚN
===============================================================================

Problema: "Element not found"
Solución:
  1. Verificar XPath en Object Repository
  2. Aumentar timeout: WebUI.waitForElementVisible(obj, 15)
  3. Abrir en navegador y confirmar elemento existe

Problema: "Login fails"
Solución:
  1. Verificar credentials en Profile
  2. Confirmar usuario tiene acceso en TEST/PROD
  3. Checar si login URL es correcta

Problema: "Screenshots no se guardan"
Solución:
  1. Crear carpeta: Resources/Screenshots/
  2. Verificar permisos de escritura
  3. Revisar valor de SCREENSHOT_DIR en Profile

Problema: "Test case toma demasiado tiempo"
Solución:
  1. Reducir timeout: WebUI.waitForPageLoad(5) en lugar de 10
  2. Usar WebUI.delay(1) en lugar de 2
  3. Ejecutar casos individuales en lugar de suite

🆘 PREGUNTAS FRECUENTES
===============================================================================

P: ¿Puedo ejecutar un solo test case?
R: Sí. Click derecho en TestCase > Run > Seleccionar Profile

P: ¿Cómo cambio entre TEST y PROD?
R: Seleccionar Profile diferente antes de ejecutar
   - ENV_TEST → Ejecuta en https://sheets-test.templet.io
   - ENV_PROD → Ejecuta en https://sheets.templet.io

P: ¿Qué significa "umbral 3%"?
R: Permite diferencia visual de hasta 3% entre TEST y PROD
   Útil para antialiasing de fonts, rendering ligero
   Valores >3% = brechas detectadas a investigar

P: ¿Cómo agrego nuevas columnas a la validación?
R: Editar TC-SHEETS-ELEMENT-003.tc
   Variable expectedColumns: "ID,Name,Status,Created,Modified,Actions,NewColumn"

P: ¿Puedo ejecutar desde línea de comandos?
R: Sí. Ver README.md para comandos katalon CLI
